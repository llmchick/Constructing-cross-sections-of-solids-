Интерактивное образовательное 3D-веб-приложение для построения и пошагового разбора плоских сечений многогранников (**параллелепипеда** и **тетраэдра**). Приложение работает **полностью офлайн** из одного самодостаточного HTML-файла и не требует подключения к интернету или установки сторонних библиотек.

---

## ✨ Основные возможности

* **Полная автономность (100% Offline):** встроенное 3D-ядро рендеринга (WebGL с автоматическим фоллбэком на 2D Canvas) и векторно-матричной математики находится прямо внутри `index.html` (~73 КБ). Никаких внешних CDN и сетевых запросов.
* **Две базовые стереометрические фигуры:**
  * **Параллелепипед** — настройка координат направляющих векторов рёбер ($ec{a}, ec{b}, ec{c}$), перетаскивание вершин и граней мышью/пальцем (с возможностью фиксации или изменения углов между рёбрами).
  * **Тетраэдр** — настройка координат четырёх вершин ($A, B, C, D$) через поля ввода или интерактивным перетаскиванием в 3D-пространстве с автоматической защитой от вырождения фигуры.
* **Построение сечения по 3 точкам:** достаточно поставить три точки на гранях фигуры двойным кликом (или двойным тапом), чтобы приложение автоматически построило секущую плоскость, многоугольник сечения, определило его вид (треугольник, четырёхугольник, пятиугольник, шестиугольник) и вычислило площадь.
* **Пошаговый разбор («Ход построения»):** интерактивный учебный режим, который по шагам демонстрирует классический метод следов:
  * проведение следов секущей плоскости в плоскостях граней;
  * поиск вспомогательных точек пересечения прямых с плоскостями граней ($X_1, X_2, \dots$);
  * нахождение узловых точек на рёбрах многогранника ($K_1, K_2, \dots$) и соединение их в итоговый многоугольник.
* **Мультиязычный интерфейс (RU / EN / ZH):** поддержка **русского**, **английского** и **китайского** языков со стартовым экраном выбора и мгновенным переключением языка на лету (включая перевод всех геометрических пояснений на каждом шаге построения).
* **Адаптивность и темы оформления:** автоматическая поддержка светлой и тёмной системных тем (`prefers-color-scheme`), адаптивная вёрстка для компьютеров, планшетов и смартфонов.

## 🎮 Управление

### 💻 На компьютере (мышь)
| Действие | Управление |
| :--- | :--- |
| **Вращение камеры** | Зажать `ЛКМ` по пустому месту и потянуть |
| **Перемещение (панорамирование)** | Зажать `ПКМ` и потянуть |
| **Масштабирование (зум)** | Колесо прокрутки мыши |
| **Изменение фигуры** *(режим настройки)* | Потянуть `ЛКМ` за оранжевую вершину или за грань параллелепипеда |
| **Поставить точку сечения** *(режим сечения)* | **Двойной клик `ЛКМ`** по грани многогранника |

### 📱 На смартфоне и планшете (сенсорный экран)
| Действие | Управление |
| :--- | :--- |
| **Вращение камеры** | Движение **одним пальцем** по пустому месту |
| **Перемещение и масштаб** | Жест **двумя пальцами** (перемещение и щипок / pinch-to-zoom) |
| **Изменение фигуры** *(режим настройки)* | Потянуть **одним пальцем** за оранжевую вершину или грань |
| **Поставить точку сечения** *(режим сечения)* | **Двойной тап** по грани многогранника |

## 🚀 Быстрый старт

### Вариант 1. Локальный запуск (без интернета)
1. Скачайте файл `index.html` (или распакуйте архив).
2. Откройте `index.html` в любом современном браузере (Chrome, Firefox, Safari, Edge) двойным кликом — на компьютере или смартфоне.

### Вариант 2. Публикация на GitHub Pages
1. Создайте новый репозиторий на GitHub.
2. Загрузите файл проекта под именем **`index.html`** в корень репозитория.
3. Перейдите в **Settings → Pages**, в разделе **Build and deployment** выберите ветку `main` (папка `/ (root)`) и нажмите **Save**.
4. Через минуту приложение будет доступно по адресу `https://<ваш-логин>.github.io/<имя-репозитория>/`.

## 🛠 Технические особенности и безопасность

* **Zero Dependencies:** приложение написано на чистом Vanilla JavaScript (ES6+), HTML5 и CSS3.
* **Безопасность:** встроен строгий заголовок `Content-Security-Policy` (`connect-src 'none'`, `object-src 'none'`), работа с DOM осуществляется безопасно через `textContent` и `createElement` без использования `innerHTML`.
* **Управление памятью WebGL:** при перестроении фигуры и переключении шагов построения все буферы геометрии (`ARRAY_BUFFER`, `ELEMENT_ARRAY_BUFFER`) корректно освобождаются в видеопамяти через `.dispose()`.

## 🌐 English Summary

**Polyhedron Cross-Sections** is a self-contained, 100% offline interactive 3D geometry web application for constructing and exploring cross-sections of a **parallelepiped** and a **tetrahedron**.
* Place 3 points on faces via double-click / double-tap to automatically compute the cross-section polygon and its area.
* Use **Show construction steps** to walk through the geometric trace method step by step.
* Supports **Russian**, **English**, and **Chinese** out of the box.

## 🇨🇳 中文简介

**多面体截面 (Polyhedron Cross-Sections)** 是一款完全离线、单文件运行的交互式 3D 立体几何教学网页应用，支持**平行六面体**和**四面体**的截面构建与分步演示。
* 在多面体的面上双击鼠标左键（或双击触摸屏）放置 3 个点，即可自动生成截面多边形并计算其面积。
* 点击 **“显示作图步骤”** 可逐步查看利用迹线法求截面的完整几何推导过程。
* 内置 **俄语**、**英语** 和 **中文** 三种语言界面。
